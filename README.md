# MXene Atlas (early stage)

An open, evidence-linked map of reported MXene properties: which MXene, made how, gives which property.
Every value links to the sentence it came from (with the paper's DOI), so it can be checked against the original.
Current counts (values, papers) are shown on the map page itself.

- Map: https://songt-50.github.io/mxene-atlas/  ·  Korean: https://songt-50.github.io/mxene-atlas/ko.html
- Explore mode (3D): https://songt-50.github.io/mxene-atlas/explore.html  ·  How to use: https://songt-50.github.io/mxene-atlas/guide.html
- Book — *A Map on Thin Sheets*: https://songt-50.github.io/mxene-atlas/book/index.en.html
- 3D explainers of MXene synthesis: https://songt-50.github.io/mxene-3d/

**Status.** Values are machine-extracted from open-access papers and checked against their source sentences by two AI models.
A mark from the two models means *the sentence states this number* — not that an MXene researcher has confirmed it is the MXene's own value.
No human expert check yet, so nothing is labelled "verified".

**Questions, corrections, removal requests.** Please open an issue or a Q&A discussion in this repository
(rights holders who would like a paper's sentences removed: requests are handled promptly).
Earlier comments (before 2026-10-17) are at https://github.com/SongT-50/mxene-3d/issues.
